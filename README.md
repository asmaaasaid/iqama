# 🕌 Prayer Times App

A simple React + Vite application to display daily prayer times for a selected city.

---

## ✨ Features
- Display prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha).
- Countdown timer for the next prayer.
- Clean and user-friendly interface.
- Fetches real data from a prayer times API.
